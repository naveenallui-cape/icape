# i-CAPE Frontend

Next.js + TypeScript frontend for the i-CAPE Olympiad Management Platform.

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

App: http://localhost:3000

## Routes (Phase 1)

| Path | Description |
|------|-------------|
| `/` | Public homepage placeholder |
| `/admin/login` | Admin login placeholder |
| `/admin/dashboard` | Admin dashboard placeholder |

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- TanStack Query
- React Hook Form + Zod
- Lucide React
- shadcn/ui-ready (`components/ui`)
